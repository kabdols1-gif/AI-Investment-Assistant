# Broker Spec Repository

Store API specs per broker here so test execution can be driven by spec files.

Folder format:

- `broker-specs/<broker-id>/<service-code>.json`
- `broker-specs/<broker-id>/<service-code>.payload.example.json`

Examples:
- `broker-specs/kbsec/SSQM2952.json`
- `broker-specs/kbsec/SSQM2952.payload.example.json`
